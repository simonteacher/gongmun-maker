3메모 쓰는 법

격식 없이 적어도 됩니다. 아래 약속만 지키면 항목 기호와 들여쓰기는 알아서 맞춥니다.

  • 첫 줄은 목적·취지 문장. "~하고자 함", "참석 바람"처럼 써도 공문 말투로 바꿔 줍니다.
  • 항목: 내용 꼴로 쓰면 가. 나. 다. 항목이 됩니다. (내 용, 총 금 액처럼 띄어 쓴 이름도 그대로 둡니다.)
  • 줄 앞에 -를 붙이면 바로 위 항목의 하위 항목 1) 2)가 됩니다.
  • 관련: 줄은 1번 관련 문서로, 붙임: 줄은 맨 아래 붙임으로 갑니다. 붙임은 쉼표로 여러 개를 쓸 수 있습니다.
  • 날짜·시간은 아무렇게나 써도 됩니다. "4월 15일 수요일 오후 3시 반"도 규정대로 바뀝니다.

4제목으로 개요 채우기

메모 칸이 비어 있을 때 제목을 쓰고 Enter를 누르거나 다른 곳을 클릭하면, 제목에 맞는 기본 개요가 자동으로 들어갑니다. 메모 칸 오른쪽 위 [제목으로 개요 채우기] 버튼으로 언제든 다시 넣을 수 있습니다.

  • 제목의 낱말로 공문 종류를 구분합니다. 연수, 협의회·회의, 체험학습, 대회·행사, 모집·채용, 조사·제출, 결과 보고, 상담 주간, 협조 요청, 운영 계획, 물품 구입, 간식비 등을 구분합니다.
  • 날짜·장소·인원·금액처럼 제목만으로 알 수 없는 내용은 ○ 칸으로 비워 둡니다. ○ 칸이 남은 채로 본문을 복사하면 알려 줍니다.
  • 이미 쓴 메모가 있으면 바꿀지 먼저 묻고, 바꾼 뒤에도 알림창의 [되돌리기]로 되살릴 수 있습니다.

6빨간 밑줄과 규정 정돈

  • 본문에서 규정과 다른 곳에는 빨간 물결 밑줄이 생기고, 아래 교정 추천 목록에 이유와 고칠 내용이 나옵니다. ∨ 표시는 띄어 쓸 자리입니다.
  • 추천 항목을 누르면 그곳으로 이동하고, [적용]으로 하나씩, [모두 고치기]로 한 번에 고칠 수 있습니다.
  • [규정 정돈]은 번호를 다시 매기고 들여쓰기·빈 줄·붙임 줄 맞춤·'끝.'까지 한꺼번에 맞춥니다. 본문을 직접 고친 뒤 눌러 주면 좋습니다.
  • 바꾼 뒤 아래에 뜨는 알림창의 [되돌리기]로 바로 전 상태로 돌아갈 수 있습니다.

8K-에듀파인에 붙여 넣기

  1. 업무포털 → K-에듀파인 → 기안 작성 화면을 엽니다. (위쪽 [업무포털] 버튼)
  2. 공문메이커에서 [제목 복사]를 누르고 에듀파인 제목 칸에 붙여 넣습니다 (Ctrl+V).
  3. [본문 복사] (또는 위쪽 [에듀파인 본문 복사])를 누르고 본문 편집기 첫 줄에 붙여 넣습니다.
  4. 붙임 둘째 줄이 첫째 줄과 맞지 않으면 [띄어쓰기 규정] 창 아래 붙임 둘째 줄 앞 공백 칸 수를 바꿉니다 (기본 9칸).
교정 추천이 남아 있거나 ○ 칸이 비어 있으면 복사할 때 알려 줍니다. 그래도 복사는 됩니다.

지출품의 품목내역 엑셀이 필요하면 위쪽 [품목내역 도우미]를 쓰세요.

9AI 설정 (선택)

AI 키가 없어도 초안 만들기, 규정 교정, 개요 채우기, 빠른 버튼이 모두 됩니다. 채팅으로 자유롭게 문장을 고치고 싶을 때만 구글 제미나이 API 키를 넣으세요.

  1. 구글 AI 스튜디오(aistudio.google.com)에 학교 구글 계정으로 들어가 Get API key → Create API key를 누릅니다.
  2. 만들어진 키를 복사해 공문메이커 위쪽 [AI 설정]에 붙여 넣고 [연결 확인] → [저장]을 누릅니다.
  3. 답이 느리면 모델을 gemini-flash-lite-latest로 바꿔 보세요.
키는 이 컴퓨터의 브라우저에만 저장되고 다른 곳으로 보내지지 않습니다. 키를 다른 사람과 공유하지 마시고, 공용 PC에서는 사용 후 [AI 설정] → [키 지우기]를 눌러 주세요. AI에 보내는 공문에 학생 이름 등 개인정보가 들어가지 않도록 주의하세요.

11자주 묻는 질문

AI 키가 없어도 쓸 수 있나요?

네. 초안 만들기, 붙여 넣은 공문 고치기, 빨간 밑줄 교정, 규정 정돈, 개요 채우기, 빠른 버튼은 모두 AI 없이 작동하고 인터넷 연결도 필요 없습니다.

작성하던 내용은 어디에 저장되나요?

쓰는 즉시 이 컴퓨터의 브라우저에 자동 저장되어, 창을 닫았다 열어도 그대로 남아 있습니다. 서버로는 보내지 않습니다. 다른 컴퓨터나 다른 브라우저에서는 보이지 않습니다.

실수로 지웠어요.

바꾸거나 지운 직후 아래에 뜨는 알림창의 [되돌리기]를 누르세요. 본문 칸에서는 Ctrl+Z도 됩니다.

에듀파인에 붙였더니 붙임 둘째 줄이 어긋나요.

[띄어쓰기 규정] 창 아래 '붙임 둘째 줄 앞 공백' 칸 수를 바꾼 뒤 [규정 정돈]을 누르고 다시 복사하세요.

'아래와 같이'를 '다음과 같이'로 바꿔야 하나요?

둘 다 틀린 표현은 아니라서 붙여 넣은 공문에서는 그대로 둡니다. 새로 만드는 초안은 '다음과 같이'를 씁니다.

1. 2. 사이 빈 줄을 없애고 싶어요.

기본은 교육청 공문처럼 1. 2. 3. 사이를 한 줄 띄웁니다. 빈 줄 없이 쓰려면 [띄어쓰기 규정] 창 아래 '1. 2. 3. 항목 사이를 한 줄 띄우기'를 끄세요.

공문에 표가 있어요.

표에서 복사한 줄(빈 줄 뒤에 기호 없이 이어지는 줄)은 고치지 않고 그대로 둡니다. K-에듀파인에 붙여 넣은 뒤 그 부분을 표로 다시 만들어 주세요. 본문이 표로 끝나면 표 아래에 2타 띄우고 '끝.'을 붙입니다.

교정이 틀린 것 같아요.

교정 추천은 고치기 전에 내용을 보여 주니, 맞지 않으면 그 항목은 고치지 않고 두면 됩니다. 본문은 언제든 직접 고칠 수 있습니다.
